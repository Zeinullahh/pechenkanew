# Руководство пользователя WebSOC

Централизованная консоль управления (CMC) WebSOC предназначена для регистрации защищаемых сервисов, выбора трафика агентов для просмотра и управления настройками защиты. Активную защиту обеспечивает Agent; управляйте ею через CMC.

## 1. Открытие панели управления

Войдите в CMC под своей учётной записью. На панели управления отображается глобус с трафиком по странам; данные периодически обновляются. Навигация включает **Dashboard**, **Compliance**, а также ссылки на сервисы WebSOC и Email Security и инструкции к продуктам.

Кнопка меню в левом верхнем углу открывает настройки отображения, языка, часового пояса, истории платежей и ключа AI API. В меню профиля доступны командный доступ, настройки оплаты, параметры учётной записи и выход.

## 2. Регистрация защищаемого сервиса

1. Откройте **Data source selection** в верхней левой части панели и выберите **Register new agent**.
2. Выберите **Website only** для сайта, защищаемого в режиме обратного прокси, или **Other services** для другого сервиса, например SMTP, пользовательского приложения или Kubernetes.
3. Введите домен и текущий хост или IP-адрес источника/сервиса. Для сайта CMC может предложить пограничный узел.
4. Для сайта отправьте форму регистрации. Следуйте показанным настройкам DNS: добавьте у DNS-провайдера запрошенную CNAME-запись делегирования ACME, а затем направьте DNS сервиса на узел WebSOC согласно инструкциям. ACME — автоматизированный процесс выпуска сертификата; записи DNS подтверждают контроль над доменом и направляют трафик.
5. После настройки CNAME выберите **Verify DNS delegation**. Интерфейс сообщит, подтверждено ли делегирование, и укажет, что также требуется запись A. При необходимости используйте **Redo verification**.
6. Для **Other services** после ввода сведений о сервисе форма покажет **Get agent install command**. Выполните инструкции, созданные для этого сервиса.

В списке агентов показаны домен, адрес и состояние каждого агента. **Active** означает, что защита активна, владение/делегирование подтверждено, а DNS направлен на узел WebSOC. **DNS pending** означает, что проверка пройдена, но трафик ещё не направляется. Также отображаются состояния **Delegation not verified** и **Paused**.

## 3. Выбор агентов и просмотр трафика

1. Откройте **Data source selection**.
2. Отметьте одну или несколько строк агентов, чтобы включить соответствующие сервисы в метрики панели. Кнопка показывает число выбранных агентов.
3. В селекторе справа выберите **RPS** (запросов в секунду), **Bandwidth** или **Active Users**. Наведите указатель на страну на глобусе, чтобы увидеть разбивку по доменам.
4. Нажмите стрелку внизу по центру, чтобы открыть **Server Load Chart** и сводки по странам с наибольшими показателями. Выберите период; выделите участок графика, чтобы ограничить сводки этим интервалом.

## 4. Настройка, приостановка, возобновление или удаление агента

Откройте **Data source selection** и используйте элементы управления в строке агента:

- Значок карандаша открывает **Agent Configuration**. Измените адрес, выберите разрешённые порты (22, 80 и/или 443), включите или отключите двухфакторную аутентификацию и нажмите **Save**.
- Значок документа открывает **Domain setup details**. Проверьте делегирование DNS, маршрутизацию, тип сервиса и состояние TLS-сертификата. TLS — это зашифрованное соединение, используемое веб-сайтами.
- Значок обновления запускает проверку владения и делегирования DNS.
- Пользователи с подходящей ролью могут приостановить защиту значком паузы или возобновить её значком воспроизведения. Приостановка с панели действует 60 минут.
- Нажмите значок корзины и подтвердите действие, чтобы удалить агента из учётной записи.

## 5. Просмотр инцидентов и предупреждений безопасности

Выберите **Incidents** слева на панели управления, чтобы просмотреть журналы событий. Фильтруйте их по источнику, степени серьёзности, типу события, IP-адресу или диапазону дат. Список разбит на страницы; используйте доступные средства экспорта, чтобы скачать подходящие журналы.

При появлении требующего действий предупреждения безопасности изучите сводку атаки, IP-индикатор и рекомендуемую длительность. Можно заблокировать источник на один из предложенных сроков или до заданного времени, разрешить источник (после подтверждения) либо передать предупреждение на следующий уровень. Выбранное действие применяется к показанному предупреждению.

## 6. Управление правилами доступа по IP

Откройте управление доступом shield/IP слева на панели. Нажмите **Add rule**, задайте параметры правила и сохраните его. С помощью элементов этой панели можно просматривать, удалять или отзывать существующие правила. Список блокировки содержит источники, которые система должна блокировать; добавляйте или удаляйте коды стран с помощью **Add** и **Remove**.

## 7. Команда и соответствие требованиям

### Team & Access

1. Откройте меню профиля и выберите **Team & Access**.
2. Нажмите **Invite**, введите электронную почту и имя пользователя коллеги, выберите роль и сохраните.
3. Просматривайте участников команды, меняйте их роли с помощью селектора или удаляйте через действия в строке. На странице также отображается журнал аудита команды.

Доступны роли **Admin**, **Analyst** и **Viewer**. Приостанавливать и возобновлять агентов могут Admin и Analyst.

### Compliance

В главной навигации выберите **Compliance**, чтобы просмотреть сводки и состояния контролей, сгруппированные по нормативной базе. Нажмите **Refresh**, чтобы обновить данные. Для каждого контроля могут отображаться состояние, дата последней проверки, следующая проверка и число элементов доказательной базы.

## 8. Общие параметры отображения и учётной записи

Кнопка меню открывает настройки вида глобуса, языка и часового пояса. В меню профиля доступны история платежей и настройки оплаты. Завершив работу, выберите **Sign out** в меню профиля.

---

## Информация, требующая подтверждения

CMC отображает сгенерированную команду установки Agent для **Other services**, однако пользовательский интерфейс не содержит полной процедуры установки для каждого типа сервиса. Следуйте команде и инструкциям для конкретного сервиса, показанным в вашей конфигурации CMC; дополнительные требования к хосту уточните у администратора WebSOC.
